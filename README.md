# Body.Care

**Science-first care for your whole body.** A static website with evidence-based guides, 6 free interactive tools, a lead-generation engine, and full monetisation built in: AdSense, affiliate, YouTube, sponsorships, donations, giveaways and awards.

- **Live (GitHub Pages):** https://webworksa1.github.io/body-care/
- **Target domain:** https://body.care
- **Stack:** plain HTML/CSS/JS generated by a small Python script. No framework, no server. Runs on the free GitHub Pages plan.

## What's inside

| Area | Pages |
|---|---|
| Content | `library.html`, 14 guides in `articles/`, `search.html` |
| Tools | `tools/`: Skin Type Quiz, Routine Builder, Ingredient Checker, Layering Checker, Sunscreen Calculator + timer, Hydration Calculator. The homepage also has a Body Care Score. |
| Lead gen | `free-plan.html` (5-step wizard, lead scoring, clinic matching), plus an exit modal, sticky CTA, and capture after every tool and inside every article |
| Revenue | AdSense slots, `picks.html` (affiliate), `videos.html` (YouTube), `advertise.html` (sponsors + clinic lead program), `support.html` (donations/membership), `contests.html` (giveaway + awards) |
| Growth | `careers.html` (writers, reviewers, creators, ambassadors), referral bonus entries, share buttons |
| Trust | `about.html` (editorial policy), `privacy.html`, `terms.html`, `disclaimer.html` |
| Tech SEO | JSON-LD (WebSite, Organization, MedicalWebPage, FAQPage, BreadcrumbList, WebApplication), `sitemap.xml`, `robots.txt`, `ads.txt`, OG image, PWA + offline |

## Switch on revenue: edit one file

Open **`assets/js/config.js`** and fill in:

1. `forms.*`: your Formspree or other webhook endpoints. **Do this first.** Until it's set, forms fall back to opening an email draft and leads are not stored anywhere.
2. `adsenseClient` and `adSlots`. Also update `ads.txt`.
3. `ga4Id`
4. `donate.*`: Stripe Payment Links, PayPal, Ko-fi and so on.
5. `amazonTag`
6. `youtubeChannel` and `videos`
7. `contest`

## Edit or add content

```bash
python3 build/build.py            # regenerates every page, sitemap and search index (Jekyll-ready)
python3 build/build.py --static   # fully rendered HTML instead, for Netlify, Vercel, Cloudflare or S3
```

- Add guides in `build/content.py`.
- Change page templates in `build/pages_main.py` and `build/pages_more.py`.
- Change the shared head, header and footer in `build/layout.py`. This also regenerates `_layouts/default.html`.

Commit and push the generated files. GitHub Pages runs its built-in Jekyll build to wrap every page in `_layouts/default.html`. No Actions workflow and no paid plan are needed.

**One-time setup:** go to **Settings → Pages → Build and deployment**, set **Source: Deploy from a branch**, then choose **Branch: `main` / `(root)`**.

**Optional:** run `build.py` locally with Pillow installed (`pip install pillow`) to create `assets/img/og-image.png` and the PNG app icons. Then upload them to `assets/img/`.

## Custom domain (body.care)

1. In GitHub, go to repo **Settings → Pages → Custom domain**, enter `body.care`, and save.
2. At the registrar, add A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`, plus a `www` CNAME pointing to `webworksa1.github.io`.
3. Tick **Enforce HTTPS** once the certificate has been issued.
